# Applied Crafted Energistics 0.2.2

Release date: 2026-11-22

> **Re-release:** the 0.2.2 artifact was rebuilt and re-published on 2026-11-22 with the project's
> source code under **LGPL-3.0-only**. The version string is unchanged; the previous 0.2.2 download
> remains subject to the licence that applied when it was originally published.

## Highlights

- **ME Gas Interface per-slot settings**: target amount, target pressure and a transfer mode for every
  marked config slot, with a gear/middle-click settings dialog.
- **New cards**: Slot Control Card, Safety Card and the bus-mounted Gas Pressure Card.
- **Stock AE2 automation**: AE2's own ME Interface, Pattern Provider, import/export bus and storage bus
  handle CCB gas keys; gas can be marked from containers, Gas Samples or JEI.
- **JEI pattern encoding**: with AE2-JEI-Integration installed, JEI's `+` encodes CCB gas inputs and
  outputs into AE2 processing patterns (gas type and amount; pressure remains machine state).
- **Save/reload stability**: gas keys now use the canonical registry gas as their primary key, fixing
  gas autocrafting plans after reopening a world.
- **1M–256M gas cells**: five new high-capacity tiers with MEGA Cells-style tier accents while keeping
  the mod's teal housing. Their default recipes use MEGA Cells housings/components and CCB airtight
  tanks. MEGA Cells is an optional prerequisite: the default recipes only load when it is installed.
- **In-game documentation**: GuideME pages for gas storage cells and interface/automation. Hovering a
  gas cell and pressing **G** opens the cell page.
- **New artwork** for the Gas Sample and the new upgrade cards.

## Configuration

```toml
[recipes]
	enable_mega_cell_recipes = true
```

Set to `false` to remove the default MEGA-gated 1M–256M recipes. The high-tier items remain registered;
a datapack can provide its own recipes. See `docs/GAS_CELLS.md`.

## Requirements

- Minecraft 1.21.1
- NeoForge 21.1.251+
- Applied Energistics 2 19.2.x
- Create 6.0.10.x
- Create: Crafted Beginning 0.1.x
- MEGA Cells 4.11.x — optional; needed only for the default 1M–256M recipes
